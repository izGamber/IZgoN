IzgoN — instalacija na Windows
==============================

1. Raspakuj ovaj folder bilo gdje (npr. Desktop).
2. Dvoklikni  IzgoN-Setup.cmd
3. Sačekaj. Kad završi, na Desktopu će ti stajati ikona "IzgoN".
4. Klikni tu ikonu kad god hoćeš otvoriti dashboard.
5. Hoćeš vidjeti da stvarno štedi? Dvoklikni  IzgoN-Test.cmd
   Pošalje tri izvještaja i ispiše koliko je bajtova otišlo, a koliko
   bi otišlo bez IzgoN-a. Traje deset sekundi.

Treba ti Docker Desktop. Ako ga nemaš, setup će ti reći i dati komandu.

Sve živi u jednom folderu: C:\Users\<ti>\IzgoN
Uklanjanje: pokreni IzgoN-Stop, pa obriši taj folder i dvije prečice.

IzgoN — Windows setup (English)
===============================

1. Unzip this folder anywhere.
2. Double-click  IzgoN-Setup.cmd
3. When it finishes there is an "IzgoN" icon on your Desktop.
4. Click that icon whenever you want the dashboard.
5. Want to see it actually save something? Double-click  IzgoN-Test.cmd
   It sends three reports and prints what each one cost on the wire
   against what it would have cost without IzgoN. Ten seconds.

Requires Docker Desktop. If it is missing, the setup says so and gives you
the one command that installs it.

Everything lives in one folder: %USERPROFILE%\IzgoN
To remove: run IzgoN-Stop, then delete that folder and the two shortcuts.
