What it does

izGon AI is a self-hosted memory backend for AI agents. It remembers:

  • Memories: Store facts, user preferences, decision rules, and context your agent should retain.
  • Activities: Log every action the agent took — useful for audit, debugging, and learning.
  • Projects: Organize memories and activities by scope (customer, use-case, context).
  • Snapshots: Save a complete snapshot of the agent's memory at any point. Restore it later to "rewind" the agent's state.

Unlike stateless LLMs, your agent now has continuity. It learns from past interactions and can reflect on them.

Why This Matters

LLMs are stateless — they have no memory between conversations. Your agent must either:

  • Compress all context into a system prompt (expensive and lossy).
  • Fetch context from a database on every call (slow and complex).
  • Run with no memory of the past (agent learns nothing, repeats mistakes).

izGon AI lets you do none of those. Your agent has a proper memory system. It stores what matters, recalls it when needed, and can reset to a known-good state on demand.

API Overview

All endpoints are self-documenting via FastAPI's interactive docs.

Memories

  • POST /api/brain/remember — Store a memory (fact, context, rule).
  • GET /api/brain/memories — List all memories, optionally paginated.
  • GET /api/brain/search — Search memories by keywords.
  • PATCH /api/brain/importance/{id} — Update memory importance (0–10).
  • DELETE /api/brain/forget/{id} — Delete a memory.

State

  • GET /api/brain/stats — Memory count, total size, last updated.
  • POST /api/brain/snapshot — Save a complete snapshot of all memories.
  • GET /api/brain/snapshots — List saved snapshots.
  • POST /api/brain/snapshot/{id} — Restore a snapshot.

Dashboard

  • GET / — Web dashboard. Real-time updates via WebSocket.

Tech Stack

  • Backend: FastAPI (async, type-safe).
  • Storage: SQLite (self-contained, no external DB).
  • Frontend: Plain HTML/JS dashboard with Socket.IO for real-time updates.
  • Deployment: Docker image available on GitHub Packages.

No cloud services required. Everything runs on your server.

Quick Start

Docker Compose (Recommended)

git clone https://github.com/izGamber/izGon-AI.git
cd izGon-AI
docker compose up -d

Dashboard: http://localhost:8001

Single Container

docker run -p 8001:8000 \
  -e DATABASE_URL="sqlite:///./data/memory.db" \
  ghcr.io/izgamber/izgon-ai:latest

Local (Python)

pip install -r requirements.txt
python -m uvicorn app.dashboard:app --host 0.0.0.0 --port 8001

First Memory

curl -X POST http://localhost:8001/api/brain/remember \
  -H "Content-Type: application/json" \
  -d '{
    "content": "The user prefers concise, actionable summaries.",
    "tags": ["user_preference", "communication"],
    "importance": 8
  }'

Search

curl http://localhost:8001/api/brain/search?q=user%20preference

Use Cases

  • Customer Support Agent: Remember customer name, past issues, preferences, and resolution patterns. Deliver personalized, informed support without reading logs each time.
  • Research Agent: Store discovered facts, sources, hypotheses, and conclusions. Build a knowledge graph across sessions.
  • Code Review Agent: Remember project conventions, common bugs, and approved patterns. Enforce consistency across reviews.
  • Tutoring Agent: Track student progress, misconceptions, learning pace, and mastered topics. Tailor explanations over time.
  • Planning Agent: Store goals, constraints, milestones, and blockers. Revisit and refine the plan across iterations.
